# CyberEscape Frontend — MERN
React + Vite responsive client for the CyberEscape Digital Safety Escape Room.

## Run
1. `npm install`
2. Copy `.env.example` to `.env` if the API is not on `http://localhost:5000/api`.
3. `npm run dev`

## Screens
Login/Register, Mission Control, timed mission player, answer explanations, badges via profile API, weak-topic analytics, mission history, leaderboard.
